# OperStack

Tools for content sites that have to rank, be cited by answer engines and convert. Everything here came out of one pipeline that publishes to eleven content sites; the free tools stay free.

| Repository | What it is | Install |
|---|---|---|
| [gates](https://github.com/oper-stack/gates) | Fifteen automated quality gates for MDX content sites | `npx @operstack/gates` |
| [astro-starter](https://github.com/oper-stack/astro-starter) | Astro starter that passes its own gates, with a fictional demo market | `git clone https://github.com/oper-stack/astro-starter` |
| [claude-plugins](https://github.com/oper-stack/claude-plugins) | Claude Code plugin: gates, answer-first writing, llms.txt, IndexNow, AI visibility | `/plugin marketplace add oper-stack/claude-plugins` |
| [audit-generator](https://github.com/oper-stack/audit-generator) | SEO, AEO and GEO audit: collect public signals, render a ten-page report | `npx @operstack/audit collect https://example.com` |
| [brand](https://github.com/oper-stack/brand) | Marks, wordmarks, social cards, brand guide | |

Site and products: [oper-stack.com](https://oper-stack.com). Mail: hello@oper-stack.com.
